⚡ 三步快速开始

第1步：安装依赖
  Windows:     pip install -r requirements.txt
  Mac/Linux:   pip3 install -r requirements.txt

第2步：安装浏览器驱动
  Windows:     python -m playwright install
  Mac/Linux:   python3 -m playwright install

第3步：批量采集（推荐）
  Windows:     python 电影数据采集器.py
  Mac/Linux:   python3 电影数据采集器.py

❓ 常见问题

Q: 登录二维码不显示？
A: 将 config/base_config.py 中 HEADLESS 设为 False

Q: 爬不到历史数据？
A: 平台搜索通常只显示近期内容，历史数据可能需要其他渠道

Q: 数据在哪里？
A: 全部保存在 data/ 目录，JSON 格式

Q: 如何转换为 Excel？
A: 修改 config/base_config.py 中 SAVE_DATA_OPTION = "excel"
